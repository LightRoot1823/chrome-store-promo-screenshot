# Themes

Pick one theme per listing set. All themes assume **white** brand/title/subtitle text.

| id | Feel | Gradient stops (left → right / angle ≈ -12°) |
|----|------|-----------------------------------------------|
| `teal-blue` | Default learning/tools | `#263E8D` → `#3152B4` → `#117D74` |
| `slate-navy` | Calm productivity | `#1B2A4A` → `#243B6B` → `#3A4F6A` |
| `forest` | Reading / accumulation | `#143D38` → `#1B5C4E` → `#2F6B4F` |
| `charcoal-teal` | High contrast modern | `#121820` → `#1A2E38` → `#0F4C46` |
| `olive-ink` | Softer, paper-adjacent (still dark) | `#2A2F28` → `#3A4540` → `#2F5548` |

## Accents (all themes)

- Soft circle A: white @ ~4.5% opacity
- Soft circle B: light teal/mint @ ~8% opacity (or match mid gradient)
- Window chrome: `#34363B`
- Traffic lights: `#FF776D` / `#FFBD55` / `#69C66D`
- Step badge ①: theme mid blue/teal @ ~94% opacity
- Step badge ②: deeper teal/green @ ~96% opacity

## Do not use

- Light cream/white backdrops with white titles
- High-saturation purple/pink “AI default” gradients unless the user explicitly wants that brand
- Different themes for each shot in the same store listing
